## AI di HP: tool proyek + download/impor GGUF

RetroBit tetap aplikasi Android native Kotlin/Compose. Mode offline tidak
memerlukan laptop, server Ollama, API key, atau kuota harian layanan AI.
Model GGUF tidak termasuk APK; download model awal tetap memakai internet.

### Yang baru
- **15 tool agen proyek**: operasi file, cari teks, informasi workspace,
  desain grayscale, SQLite, permintaan secret/placeholder, dan validasi struktur.
  Buka **menu proyek → Tool agen** untuk katalog lengkap. File panjang bisa
  dibaca bertahap agar bagian akhir tidak hilang dari konteks model kecil.
- **Download GGUF langsung** dari URL HTTPS, rekomendasi Qwen resmi, progres,
  pembatalan, SHA-256 penerbit opsional, serta hash salinan yang ditampilkan.
  Impor berkas lewat pemilih Android tetap tersedia. Batas satu berkas 3 GiB.
- File download parsial/header salah/ukuran tidak cocok/checksum salah tidak
  mengganti model aktif. Download/impor sukses mengganti satu slot model aktif.
- Grammar native + validasi JSON/skema sebelum eksekusi tool; log langkah dan
  file yang benar-benar berubah. Maksimum **14 langkah per sesi**, bukan kuota
  harian. Chat biasa tetap streaming dan tidak menjalankan tool.
- Batas SQL diterapkan juga pada bridge JavaScript preview agar kode proyek
  tidak melewati guard agen lewat ATTACH/PRAGMA/extension loading.
- Seluruh peran warna Material, termasuk dialog/menu, memakai palet e-paper.

### Pakai dari HP saja
1. Unduh **app-release.apk** di bawah dan pasang sebagai update. Tidak perlu
   menghapus aplikasi lama; uninstall menghapus data/model privat.
2. Buka **Cloud → AI di HP (offline)**, tekan **Periksa mesin**.
3. Pilih **Pakai rekomendasi Qwen 1.5B Q4 → Download & impor GGUF**, atau pilih
   **Impor GGUF** jika sudah punya berkas. Gunakan Wi-Fi; biarkan aplikasi terbuka.
4. Tekan **Setelan agen: 4096 / 1024 token → Simpan → Uji model**.
5. Buat proyek/template di Beranda, lalu beri tugas di **Chat proyek**.
   Chat biasa di tab utama hanya untuk obrolan, bukan operasi file proyek.

### Status preview dan batasan
- Build melewati unit/Robolectric tests, pemeriksaan tanda tangan, ABI dan
  alignment native 16 KB. Grammar native diuji tanpa model weights.
- **Belum diuji dengan GGUF nyata atau benchmark GT 30 Pro.** Tes model memakai
  backend palsu; tes HTTP memakai MockWebServer, bukan download Qwen multi-GB.
  Kecepatan dan kemampuan mengikuti tool bergantung model/perangkat.
- Download belum mendukung resume atau layanan background. Pembatalan saat
  read jaringan terhenti bisa menunggu timeout 20 detik. Pilih model tepercaya;
  HTTPS/header tanpa hash penerbit bukan bukti keaslian/kompatibilitas.
- Snapshot memulihkan **file**, bukan database; tool yang selesai tidak otomatis
  di-rollback jika sesi berikutnya gagal/dibatalkan.
- **Belum ada compiler/build/signing APK hasil proyek**, inspeksi APK atau shell.
  Preview proyek masih HTML/CSS/JS; ZIP source bukan APK siap dipasang.
- Signer demo lama dipertahankan untuk kompatibilitas update. Prerelease ini
  tidak mengganti v0.5.1 sebagai rilis stabil terbaru.
