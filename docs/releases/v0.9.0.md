# RetroBit v0.9.0 — AI nyata sebagai alur utama

Rilis stable untuk fungsi yang tersedia, bukan label “final tanpa bug selamanya”.
APK Android Kotlin/Compose tetap native, grayscale e-paper dan Pixel Operator.

## Bukan demo bawaan
- Instalasi baru memakai **AI di HP**, bukan simulator template.
- Pengaturan DEMO bawaan versi lama dimigrasikan sekali ke penyiapan AI di HP.
  Provider cloud nyata, API key, proyek, chat, persona dan model lama dipertahankan.
  Simulasi masih dapat dipilih secara eksplisit dan diberi label bukan AI.
- Dashboard memiliki **Siapkan AI di HP**. Tidak mengaku terhubung jika model
  belum ada. Gagal/absen model tidak pernah dialihkan diam-diam ke simulasi.
- Download atau impor GGUF yang berhasil otomatis mengaktifkan backend lokal
  bila tidak ada provider cloud aktif. Provider cloud yang sudah dipilih tidak
  ditimpa. Model privat lama diaktifkan kembali bila diperlukan pada startup.
- Uji model memerlukan **jawaban nonkosong dari model**, bukan sekadar library
  bisa dimuat, bukan respons “OK” palsu ketika output kosong.

## Cara pakai di HP (tanpa laptop/API key)
1. Pasang `app-release.apk` sebagai update, jangan uninstall.
2. Ketuk **Siapkan AI di HP** di Beranda.
3. Dengan Wi-Fi dan ruang kosong cukup, tekan **Download & impor GGUF**.
   URL bawaan Qwen2.5-Coder 1.5B Instruct Q4_K_M sekitar 1,12 GB. Satu kali
   download ini wajib: APK tidak menyertakan bobot AI. Bisa impor model yang
   sudah ada sebagai alternatif. Jangan memilih model dari sumber tak dipercaya.
4. Tunggu selesai; model otomatis aktif bila sebelumnya belum memakai cloud.
   **Uji model** memuat model dan meminta jawaban nyata. Lalu gunakan Chat atau
   agen proyek. Jika sudah memakai cloud, pilih AI di HP lalu Simpan untuk pindah.

## Pengujian dan batas klaim
- CI menambahkan model Instruct Qwen2.5-Coder **0.5B Q4_K_M sungguhan**: metadata
  publisher dipetakan ke revision immutable, ukuran/LFS SHA-256 diverifikasi,
  lalu UI aplikasi mengunduh lewat HTTPS dengan checksum penerbit → penyimpanan
  privat → llama.cpp/JNI → jawaban. Model referensi host tidak disisipkan ke
  data privat aplikasi untuk melewati downloader.
  Ini berbeda dari fixture vocab/header, fake backend, dan engine probe lama.
- Automasi pemilih file sistem (SAF) belum berhasil memilih file di emulator;
  impor GUI/manual pada perangkat nyata **belum diklaim terverifikasi**. Rilis
  menargetkan alur utama Download langsung; fungsi copy/hash impor diuji unit.
- Hasil CI hanya boleh dinyatakan lulus setelah job sukses. Model CI kecil
  bukan benchmark rekomendasi 1.5B pada GT 30 Pro/Android16; kualitas/kecepatan
  tidak dijanjikan sama dengan model cloud atau Arena.
- Download foreground-only, belum resume/background. Offline tidak memakai
  kredit API tetapi tetap dibatasi RAM/storage/panas, konteks 4096/output1024,
  dan 14 langkah per sesi agen. Tidak ada jaminan semua GGUF kompatibel.
- Fitur saat ini: file/tool proyek, preview HTML/CSS/JS, desain, SQLite, vault,
  AI cloud/offline, ekspor source ZIP, serta inspeksi statis APK.
  **Compiler/build/sign APK hasil proyek belum tersedia.** ZIP source bukan APK.
- Penandatangan fallback repo yang lama tetap dipakai untuk kontinuitas update;
  kunci demo publik **bukan kunci produksi privat**. Distribusi produksi ke
  pihak lain memerlukan konfigurasi signing private tersendiri.
- Hardening v0.8.1 tetap berlaku, termasuk perubahan origin/localStorage lama
  dan batas preview/snapshot. [Rincian](../HARDENING.md).
