## Audit stabilitas dan batas akses

Android native Kotlin/Compose, tetap e-paper grayscale + Pixel Operator.
Ini hardening berdasarkan temuan yang dapat diuji, **bukan janji bebas bug
selamanya**. Pasang app-release.apk sebagai update, jangan uninstall.

### Perbaikan
- Preview LAN memakai batas path canonical proyek: `_meta`, traversal URL dan
  symlink keluar proyek ditolak. .git, .env dan berkas kunci JKS/keystore juga diblokir. Tidak ada wildcard CORS. Missing asset menjadi
  404 (bukan HTML fallback), GET/HEAD saja, file ≤64 MiB disalurkan streaming,
  maksimum 8 klien aktif, request-line deadline, stop menutup soket klien.
- Preview WebView tidak lagi mengizinkan file:// / content:// atau universal
  file access. Setiap proyek punya origin HTTPS virtual lokal yang terpisah.
  Sibling JS/CSS/font dilayani lewat resolver proyek. CSP melarang frame/object
  karena JavascriptInterface tersedia ke semua frame; navigasi luar tidak
  mendapat halaman top-level dengan native bridge. HTML ≤2 MiB.
- Snapshot divalidasi lengkap di staging disk sebelum sumber aktif disentuh:
  CRC/ukuran, traversal/metadata/alias duplikat, jumlah/total/per-file dibatasi.
  Commit lewat rename + backup, rollback saat gagal dan journal untuk mencoba
  pemulihan commit terputus saat proyek dibuka ulang. Metadata/database tidak
  ikut dipulihkan. Tidak menampung seluruh arsip dalam ByteArray.
- Mutasi sumber dikunci bersama antar-handle proyek. Penulisan source, indeks
  proyek dan chat memakai temp + fsync + atomic replace, bukan truncate awal.
  Snapshot konteks hanya membaca prefix teks yang dibutuhkan.
- Timeout pembacaan SSE AI tidak lagi dianggap jawaban sukses yang terpotong.
- Hapus model GGUF diberi busy guard agar ketukan berulang tidak mengantre
  penghapusan yang bisa berjalan setelah impor baru. Cancellation diteruskan.

### Perubahan kompatibilitas / batas
- WebView origin berubah dari file://. localStorage lama **tidak dimigrasikan
  otomatis**, untuk mencegah tercampurnya data antarproyek. Proyek, SQLite,
  chat, vault dan model privat tidak sengaja dihapus oleh perubahan origin ini.
- Frame/embed object dan mixed HTTP resources tidak didukung dalam embedded
  preview. Script proyek/CDN tetap kode tepercaya dan bisa memakai SQLite
  proyek serta secret yang pengguna memang expose. Ini bukan sandbox malware.
- LAN tetap opt-in, tanpa autentikasi/TLS: siapa pun yang dapat menjangkau
  port server dapat membaca source proyek; gunakan jaringan tepercaya dan
  matikan setelah dipakai. Jangan port-forward ke internet.
- Restore: arsip ≤192 MiB, ≤2.000 entry, isi ≤128 MiB total / ≤32 MiB per file.
  Backup pemulihan dipertahankan bila filesystem menolak rollback; bukan
  jaminan recovery dari kerusakan media/power loss. Snapshot source bukan
  backup SQLite/vault. Jangan menjalankan pemulihan saat agen mengedit.
- Tidak menambah compiler APK hasil proyek. Inferensi GGUF nyata, cloud API
  live dan GT 30 Pro/Android 16 masih perlu pengujian perangkat nyata.
- Signer demo bukan kunci produksi privat. Prerelease, tidak mengganti latest
  stable. APK smoke dibangun terpisah dari asset publikasi pada source yang sama.
