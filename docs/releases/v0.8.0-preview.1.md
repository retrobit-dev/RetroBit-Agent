## Inspeksi APK langsung dari HP

Aplikasi tetap Android native Kotlin/Compose, grayscale e-paper, font Pixel
Operator. Fitur agen offline dan download/impor GGUF dari v0.7 dipertahankan.

### Yang baru
- **Menu → Inspeksi APK → Pilih APK**, tanpa memasang atau menjalankan APK.
- Package ID, versi, SDK, debuggable, permission diminta dan daftar komponen.
- SHA-256 APK serta fingerprint sertifikat/riwayat signer yang dilaporkan Android.
- Daftar berkas ZIP, DEX/resource/asset, ABI native dan pencarian nama berkas.
- **Analisis APK RetroBit** untuk mencoba pada base APK sendiri, tanpa file lain.
- Salin ringkasan dan simpan JSON lewat pemilih lokasi Android.
- Salinan sementara tidak ikut backup, dibersihkan setelah analisis/cancel/gagal.

### Cara pakai
1. Pasang **app-release.apk** sebagai update; jangan uninstall jika ingin
   mempertahankan proyek/model privat.
2. Buka **Menu → Inspeksi APK**.
3. Tekan **Analisis APK RetroBit** atau pilih berkas APK milik Anda.
4. Gunakan tab Ringkasan, Izin, Sertifikat, Komponen dan Berkas.
5. Simpan laporan JSON jika diperlukan. APK tidak disertakan dalam laporan.

### Batas preview
- Maksimum satu APK 256 MiB, 20.000 entry ZIP. Tampilan/JSON maksimum 2.000
  entry, 500 permission dan 200 komponen; total tetap dicatat. Filter hanya
  mencari entry yang ditampilkan. APK besar/ZIP64/paket terproteksi/split bisa
  ditolak. Batas metadata tambahan dijelaskan dalam panduan.
- Identitas sertifikat dari Android **bukan verifikasi kriptografi penuh APK**,
  scanner malware atau bukti aplikasi aman/asli. Permission diminta belum tentu
  diberikan. Exported bukan otomatis rentan.
- Tidak ada dekompilasi, dekripsi, bypass proteksi, atau source server.
- Pembatalan perlu menunggu I/O provider/parsing Android yang sedang berjalan;
  belum ada layanan background atau resume.
- Belum diuji langsung pada GT 30 Pro/Android 16. Inferensi GGUF nyata dan
  benchmark model juga masih belum diverifikasi.
- Belum ada compiler/build/signing APK hasil proyek; ZIP source bukan APK siap
  instal. Signer demo tetap tersedia untuk kontinuitas. Ini prerelease,
  bukan pengganti v0.5.1 sebagai latest stable.
